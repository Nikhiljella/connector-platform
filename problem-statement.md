How do I design the platform so that onboarding a new vendor type or adding a new requirement is a configuration exercise, not a coding exercise — and only when the existing building blocks genuinely can't express what's needed, does an agentic workflow step in to generate the missing piece, with human review as the only gate?
The two-tier goal:

Tier 1 — Metadata composition: New requirements satisfied by describing them in metadata that recomposes existing functionality. Zero new code.
Tier 2 — Agentic generation fallback: When metadata hits a genuine capability gap, agents generate the new building block, which then becomes reusable for future metadata-driven scenarios.
